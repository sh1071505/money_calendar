# 월간 리포트 작성 규칙

매월 1일 아침에 지난달 내용을 담은 리포트를 `reports/YYYY-MM.json`으로 만든다 (YYYY-MM = 이번 달).
작성 후 `reports/index.json`의 `months` 배열에 추가하고 `latest`를 갱신한다(오래된 달은 유지).

## 파일 형식
```json
{
  "month": "2026-11",            // 리포트가 나온 달
  "period": "2026-10",           // 뉴스가 다루는 달 (지난달)
  "generated": "2026-11-01T07:10:00+09:00",
  "headline": "지난달을 2~3문장으로 정리한 총평 (해요체)",
  "fx": {
    "asOf": "2026-11-02",        // 이번 달 첫 영업일 기준
    "source": "ECB 기준환율 (Frankfurter)",
    "rates": {"USD": 1361.27, "JPY": 8.6165, "CNY": 203.04, "EUR": 1537.96, "GBP": 1801.46},
    "prev": {"asOf": "2026-10-01", "rates": { ... 지난 리포트의 rates ... }}
  },
  "news": {
    "country": {"미국": [3개], "한국": [3개], "중국": [3개], "일본": [3개], "유럽": [3개]},
    "asset":   {"주식": [3개], "크립토": [3개], "부동산": [3개], "금리·채권": [3개]}
  }
}
```
뉴스 항목: `{"title": "", "summary": "", "source": "매체명", "url": "https://...", "date": "YYYY-MM-DD"}`

## 환율
- `https://api.frankfurter.dev/v1/{날짜}?from=EUR&to=KRW,USD,JPY,CNY,GBP` 로 받아 1단위당 원화로 교차 계산한다.
  (원화/X = rates.KRW / rates.X, EUR은 rates.KRW 그대로) JPY는 1엔당 값(소수 4자리)으로 저장한다.
- `prev`는 직전 리포트 파일의 `fx.rates`와 `fx.asOf`를 그대로 쓴다.

## 뉴스
- 지난달에 실제로 있었던 일만, 출처 링크와 함께. 숫자는 원문에서 확인한 것만 쓴다. 추측·전망 문장은 출처가 말한 범위에서만.
- 요약은 해요체 2~3문장, 개인 투자자가 알아야 할 포인트 중심. 각 항목은 서로 겹치지 않게.
- 사용자는 해외주식(미국) 위주로 투자하고 비트코인을 보유하며 신용대출이 있다. 미국 증시·금리·환율·비트코인 관련 내용을 빠뜨리지 않는다.
